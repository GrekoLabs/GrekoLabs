# GrekoLabs

GrekoLabs es un portfolio tecnológico para reunir proyectos de desarrollo web, análisis de datos, machine learning y computación científica.

## Estructura

- `website/`: sitio principal del portfolio, previsto en Next.js y TypeScript.
- `projects/`: proyectos independientes del laboratorio.
  - `bitcoin-analytics/`: análisis y visualización de datos relacionados con Bitcoin.
  - `facial-recognition/`: experimentación con visión por computador y reconocimiento facial.
  - `numerical-analysis/`: implementaciones y estudios de métodos numéricos.
- `infrastructure/`: configuración compartida de infraestructura y servicios, incluido PostgreSQL mediante Docker.
- `docs/`: documentación general, decisiones técnicas y guías del proyecto.

Cada área se inicializará con sus herramientas y dependencias cuando su alcance esté definido.
